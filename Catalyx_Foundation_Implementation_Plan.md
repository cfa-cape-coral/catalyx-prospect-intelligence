# Foundation Application Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the first working Catalyx Prospect Intelligence application shell with placeholder routes, navigation, tests, and setup documentation.

**Architecture:** Build a single Next.js App Router application in TypeScript. Use shared layout components for navigation and page framing, route-level pages for the four approved screens, and lightweight automated tests that verify every placeholder route renders and navigation targets exist. This milestone intentionally contains no database, authentication provider, AI, OCR, search, storage, or background jobs.

**Tech Stack:** Next.js, React, TypeScript, ESLint, Vitest, React Testing Library, npm.

## Global Constraints

- Repository name: `catalyx-prospect-intelligence`.
- Repository visibility: private.
- Primary user: Daniel only.
- Use Next.js with TypeScript and the App Router.
- Use Server Components where practical.
- Build a responsive web interface.
- Do not add Supabase in this milestone.
- Do not add authentication logic in this milestone.
- Do not add AI, OCR, public web search, storage, or background jobs in this milestone.
- Do not implement real prospect persistence in this milestone.
- All placeholder routes must render.
- Navigation, type checking, linting, and automated tests must pass before completion.
- Never commit secrets or local environment files.

### File responsibilities

- `app/layout.tsx`: Root HTML structure and shared application chrome.
- `app/page.tsx`: Redirects the root route to `/dashboard`.
- `app/login/page.tsx`: Placeholder login screen with disabled form behavior.
- `app/dashboard/page.tsx`: Placeholder dashboard screen.
- `app/prospects/new/page.tsx`: Placeholder manual prospect-entry screen.
- `app/prospects/[prospectId]/page.tsx`: Placeholder prospect-profile screen using the route parameter.
- `components/app-header.tsx`: Shared navigation header.
- `components/page-shell.tsx`: Shared responsive page width, heading, and description wrapper.
- `components/placeholder-card.tsx`: Reusable placeholder panel for unfinished sections.
- `lib/navigation.ts`: Single source of truth for top-level navigation links.
- `tests/*`: Route, component, and navigation-contract tests.
